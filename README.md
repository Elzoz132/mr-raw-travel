# Mr.Raw Travel - Premium Tourism & Excursions Platform

Enterprise-grade international tourism booking platform engineered with Next.js 15, TypeScript, Tailwind CSS, and Prisma ORM.

## Features
- **Multi-Currency Engine:** Live rate conversions across USD ($), EUR (€), EGP, and GBP (£).
- **Multi-Language i18n:** Full support for English, Arabic (RTL), and German.
- **High-Conversion Booking Engine:** 4-step instant reservation workflow with payment receipt upload.
- **Executive Operations CMS:** Protected admin backoffice dashboard (`/admin/dashboard`), trip manager (`/admin/trips`), promo coupons (`/admin/coupons`), and customer directory (`/admin/crm`).
- **Digital VIP Voucher:** Dynamic QR Token generator and printable confirmation vouchers.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
